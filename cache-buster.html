Attenzione

Questo tool aggiorna automaticamente tutti i query string ?v=YYYYMMDDXX nei file HTML.

Effetto: Tutti gli utenti scaricheranno le versioni aggiornate di CSS/JS alla prossima visita.

File che verranno aggiornati:

  • resources/sheet.css?v=20260920-final>
  • resources/*.js (tutti i JavaScript)
  • Tutti i file HTML con query string

Come Funziona

  1. Clicca "Genera Nuova Versione" per creare un nuovo timestamp
  2. Clicca "FORZA REFRESH CACHE GLOBALE"
  3. Scarica i file HTML modificati
  4. Carica i file su Firebase Hosting
  5. Fai firebase deploy --only hosting

Nota: Questo tool genera un file ZIP con tutti gli HTML modificati. Non modifica direttamente i file sul server.

Alternative Veloci

Oppure incrementa manualmente la versione in sw.js e rideploya.
