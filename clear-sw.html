Quando usare:

• Errori "Failed to fetch" infiniti

• Foto non appaiono anche se caricate
✅ Operazione completata! Ricarica la pagina (F5)

🔧 Istruzioni Manuali

  1. Premi CTRL + SHIFT + F5 (hard refresh)
  2. Apri DevTools (F12) → Application → Service Workers
  3. Click "Unregister" su tutti i worker
  4. Application → Cache Storage → Delete all
  5. Ricarica pagina
