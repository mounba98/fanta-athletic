# Archivio — file tenuti per riferimento, non usati dall'app

Niente di quello che c'è qui viene caricato dal sito, e la cartella non viene
pubblicata (`firebase.json` la esclude). Ogni spostamento qui è registrato in
`docs/DECISION_LOG.md` con il perché.

- `versioni-precedenti/` — copie di un file **prima** di una modifica grossa, col
  numero di decisione nel nome (es. `index-pre-D109.html` = la Home prima di D109).
  Servono per confrontare o tornare indietro.
- `resources-orfani/` — script e dati non più caricati da nessuna pagina: l'inizio
  del progetto "ampliamento futuro" (D014/D018), i pezzi della vecchia Home
  sostituiti in D109, dati di prova di una lega vecchia (D118).
- `pagine-abbandonate/`, `pagine-obsolete/` — pagine non più raggiungibili (D008, D019, D034 e successive: vedi il diario).
- `admin-legacy/` — vecchi strumenti del pannello admin (D034).
- `fix-debug-migrazione/` — pagine di correzione/debug usate una volta sola.
- `test/` — pagine di prova.
