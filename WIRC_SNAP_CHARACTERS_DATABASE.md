## 🎴 COME AGGIUNGERE IMMAGINI A WIRC SNAP

### Metodo 1: Carte Personaggi (Card Images)
**Path**: `resources/wirc-cards/`

1. **Crea le immagini**:
   - Dimensioni: **300x420px** (ratio 5:7 come Marvel Snap)
   - Formato: PNG o WEBP (trasparenza consigliata)
   - Naming: `{character-id}.png` (es. `fracks.png`, `chep.png`)

2. **Design suggerito**:
   - Border neon (colore fazione)
   - Foto/illustrazione personaggio al centro
   - Nome in alto (font: Bebas Neue)
   - Stats in basso (Cost/Power)
   - Effetto glow per rarità

3. **Integrazione codice**:
```javascript
// In wirc-snap-marvel.html (linea ~180)
function createCardElement(card) {
  const imgSrc = card.image || `resources/wirc-cards/${card.id}.png`;
  return `
    <div class="card" data-id="${card.id}">
      <img src="${imgSrc}" onerror="this.src='resources/logo.png'" />
      <div class="card-cost">${card.cost}</div>
      <div class="card-power">${card.power}</div>
    </div>
  `;
}
```

### Metodo 2: Location Images (Sfondi Location)
**Path**: `resources/wirc-locations/`

1. **Crea sfondi**:
   - Dimensioni: **400x200px**
   - Formato: JPG o WEBP
   - Naming: `{location-id}.jpg` (es. `circolo-wirc.jpg`)

2. **Location suggerite WIRC**:
   - **Circolo WIRC** (casa base)
   - **Bar Gilli** (Bergit location)
   - **Campo Athletic** (stadio)
   - **Pignone** (Wabione/Canni work)
   - **Stadio Franchi** (Viola fans)
   - **Piazza Santa Croce** (centro Firenze)

3. **Integrazione CSS**:
```css
.location[data-id="circolo-wirc"] {
  background-image: url('resources/wirc-locations/circolo-wirc.jpg');
  background-size: cover;
}
```

### Metodo 3: Avatars (Foto Profilo Utenti)
**Path**: Storage Firebase `avatars/{uid}/profile.jpg`
- Già implementato in `user-profile-upload.html`
- Carica da Firestore automaticamente

### Metodo 4: Icons & Effects
**Path**: `resources/icons/`
- Fazioni: `blortz-icon.svg`, `mini-blortz-icon.svg`
- Effetti: `smoke.png`, `glow.png`, `sparkle.gif`

### Automation
- **Python Script**: Batch resize + rename
```python
from PIL import Image
import os

for filename in os.listdir('raw/'):
  img = Image.open(f'raw/{filename}')
  img = img.resize((300, 420))
  name = filename.lower().replace(' ', '-')
  img.save(f'resources/wirc-cards/{name}')
```
