## 🚨 TROUBLESHOOTING

### "Link non funziona"
**Fix**: Verifica che il link sia completo con `https://`

### "Codice non si inserisce automaticamente"
**Fix**: Copia link completo con `?code=CSJVAV` alla fine

### "Non vedo squadre disponibili"
**Causa**: Nessuna squadra creata nella lega

**Fix**:
```
1. admin.html → Gestione Squadre
2. Crea squadre (Rossi, Blu, Verdi, etc)
3. User riprova
```

### "Non posso inserire formazione"
**Causa 1**: Non assegnato a squadra

**Fix**: admin.html → Squadre → Assegna user

**Causa 2**: Deadline scaduta

**Fix**: sblocca-formazioni-temp.html → Sblocca

**Causa 3**: Giornata non selezionata

**Fix**: matchday.html → Dropdown giornata → Seleziona 2
