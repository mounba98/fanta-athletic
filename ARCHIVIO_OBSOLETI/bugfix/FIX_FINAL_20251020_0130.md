### 2. ✅ Permission Denied Notifications
**Problema**: `[code=permission-denied]: Missing or insufficient permissions`  
**Fix**: Aggiunto regole Firestore per notifications collection

```javascript
match /notifications/{notificationId} {
  allow read: if resource.data.userId == request.auth.uid;
  allow create: if isSignedIn();
  allow update: if resource.data.userId == request.auth.uid;
  allow delete: if resource.data.userId == request.auth.uid || isAdmin();
}
```

**Deploy**: `firebase deploy --only firestore:rules` ✅

### 3. ✅ Error Logger Pulito
**Problema**: Vecchi errori (22:11, 22:25, etc.) sempre in console  
**Fix**: Auto-cleanup errori > 24h

```javascript
// Clear old errors (older than 24h)
const dayAgo = Date.now() - (24 * 60 * 60 * 1000);
const recentErrors = errors.filter(e => {
  const errorTime = new Date(e.timestamp).getTime();
  return errorTime > dayAgo;
});
```

**Risultato**: Console mostra solo "Recent Errors (24h)"
