# 📱 Come installare Fanta Athletic 2018 su iOS

## Installazione da Safari

1. **Apri Safari** sul tuo iPhone/iPad
2. Vai su https://fanta-athletic.web.app
3. Tocca il pulsante **Condividi** (icona quadrato con freccia verso l'alto)
4. Scorri verso il basso e tocca **"Aggiungi a Home"**
5. Conferma il nome "Athletic 2018"
6. Tocca **"Aggiungi"**

L'app apparirà nella tua schermata Home con il logo dell'Athletic!

## Nota sul Logo

Se il logo appare ovale o con sfondo bianco:
- Assicurati che il file `resources/logo.png` sia un'immagine **quadrata** (es. 512x512px)
- L'immagine deve avere sfondo **trasparente** o **rosso** (#dc143c)
- Il logo deve essere **centrato** nell'immagine

## Colori Athletic 2018

- **Rosso**: #dc143c
- **Blu**: #1e3a8a
- **WIRC** (circolo)
