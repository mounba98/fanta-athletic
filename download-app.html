📋 Come installare l'App Web (PWA)

1

Chrome/Edge Desktop

Clicca sull'icona "Installa" nella barra degli indirizzi o usa il menu ⋮ → "Installa Fanta Athletic"

2

Chrome Mobile

Apri il menu ⋮ → "Aggiungi alla schermata Home" → "Aggiungi"

3

Safari iOS

Tocca il pulsante Condividi 📤 → "Aggiungi alla schermata Home" → "Aggiungi"

4

Safari macOS

Menu Safari → "Aggiungi alla schermata Home" o usa il pulsante Condividi
